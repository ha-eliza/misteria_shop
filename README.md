# MISTERIA — интернет-магазин одежды

Одностраничное приложение (SPA) для интернет-магазина одежды. Реализовано на **Vue 3** с использованием **Composition API**, **TypeScript**, **Pinia**, **Vue Router** и **Tailwind CSS**.

## 🛠️ Стек технологий

- **Vue 3** (Composition API, `<script setup>`)
- **TypeScript**
- **Pinia** — управление состоянием (корзина, лайки, авторизация)
- **Vue Router** — маршрутизация
- **Tailwind CSS** — стилизация
- **Cypress** — E2E-тесты
- **Vite** — сборка

## ✨ Функционал

- 📦 **Каталог товаров** — загрузка с API (DummyJSON)
- 🔍 **Поиск** — живой поиск с выпадающим списком результатов
- 🛒 **Корзина** — добавление, удаление
- ❤️ **Лайки** — добавление в избранное с сохранением в localStorage
- 👤 **Авторизация** — вход по номеру телефона (имитация)
- 📋 **Личный кабинет** — табы «Корзина» и «Лайки»
- 📱 **Адаптивная вёрстка** — mobile-first
